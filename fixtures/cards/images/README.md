# 카드 이미지

카드 규칙 JSON의 `art.image`가 가리키는 파일을 여기에 둔다. 파일 이름이 곧 키다.

```json
"art": { "image": "jungsuk2-shopping.png", "bg": "#0a2f5e", "fg": "#ffffff" }
```

빌드 CSP가 `img-src 'self' data:`라서 **카드사 서버의 이미지 URL을 그대로 쓸 수 없다.**
쓰려면 파일을 내려받아 이 디렉터리에 두어야 한다. 파일이 없으면 화면은 `bg`·`fg`로 카드
모양을 그리고, 그것도 없으면 카드 id에서 색을 만들어 쓴다 — 어느 경우에도 계산은 같다.

카드사 이미지를 저장소에 담는 것은 저작권 판단이 필요한 일이라, 기본으로는 아무 파일도
두지 않는다.
